About me

Platform and infrastructure engineer with 6+ years building, automating and running hybrid cloud environments: Microsoft Azure, Google Cloud and on-prem VMware.

My work sits where infrastructure meets automation: Terraform/Terragrunt for provisioning, Ansible, Rundeck and Ansible AWX for configuration and operations, GitLab CI/CD for delivery, on a solid Linux and Windows Server foundation.

I enjoy automating repetitive work and making systems reliable, documented and easy to operate.
